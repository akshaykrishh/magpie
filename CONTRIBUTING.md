# Contributing to magpie

The full contributing guide -- dev setup, what CI checks before a PR, and a good first issue --
lives on the docs site: **[akshaykrishh.github.io/magpie/docs/contributing](https://akshaykrishh.github.io/magpie/docs/contributing)**.

In short:

```sh
git clone https://github.com/akshaykrishh/magpie.git
cd magpie/apps/desktop
pnpm install
pnpm tauri dev
```

Push access is held by the maintainer alone; open a PR and it'll be reviewed. This project
follows a [Code of Conduct](CODE_OF_CONDUCT.md).
